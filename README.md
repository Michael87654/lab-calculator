# Калькулятор на GitHub Pages: бесплатно, с установкой и офлайн-работой

Приложение уже готово для GitHub Pages. Код калькулятора, интерфейс, стили, manifest.json и Service Worker менять не требуется. Все адреса файлов относительные и работают в подпапке репозитория.

GitHub Pages бесплатно размещает этот статический сайт из публичного репозитория на GitHub Free. Сайт получает HTTPS-адрес вида `https://ВАШ-ЛОГИН.github.io/lab-calculator/`. Покупать домен и оплачивать сервер не нужно.

## 1. Загрузите готовые файлы

1. Скачайте и распакуйте `github-pages.zip`.
2. Войдите в GitHub и создайте новый репозиторий с именем `lab-calculator`. Выберите **Public**. Можно оставить создание README выключенным: нужный README уже есть в архиве.
3. В пустом репозитории нажмите **uploading an existing file**. Если репозиторий уже содержит файлы: **Add file → Upload files**.
4. Перетащите **содержимое распакованного архива**, включая папку `icons`, в область загрузки. Сам ZIP загружать не нужно.
5. Нажмите **Commit changes**, чтобы сохранить файлы в ветке `main`.

В корне репозитория должна получиться такая структура:

```text
index.html
manifest.json
sw.js
.nojekyll
README.md
icons/
  icon-192.png
  icon-512.png
```

`index.html` должен находиться непосредственно в корне: не в папке `outputs` или `github-pages`. Пустой `.nojekyll` отключает обработку файлов через Jekyll. Файлы `work`, старый `changes.diff` и прочие рабочие материалы загружать не нужно.

## 2. Включите GitHub Pages

1. В репозитории откройте **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь успешной публикации: она может занять до 10 минут. Статус виден в **Actions**, а ссылка **Visit site** — в **Settings → Pages**.
5. Откройте опубликованный адрес с **https://**. Для домена `github.io` HTTPS предоставляется автоматически; оставьте **Enforce HTTPS** включённым, если этот параметр доступен.

Нужен именно адрес вида `https://ВАШ-ЛОГИН.github.io/lab-calculator/`, а не страница файлов `github.com/ВАШ-ЛОГИН/lab-calculator` и не локальный адрес `file://`.

## 3. Установите на Android через Chrome

1. Включите интернет и откройте опубликованный HTTPS-адрес в обычном Chrome на телефоне, не внутри встроенного браузера мессенджера.
2. Дождитесь полной загрузки. Service Worker установится в фоне и сохранит HTML, манифест и обе иконки. После первой загрузки дайте ему завершить установку и обновите страницу один раз с включённым интернетом.
3. Откройте меню Chrome **⋮ → Установить и создать ярлык → Установить**. В другой версии Chrome пункт может называться **Добавить на главный экран** или **Установить приложение**.
4. На главном экране появится иконка калькулятора. Приложение будет открываться отдельным окном благодаря `display: "standalone"`.

Если Chrome не предлагает установку сразу, дождитесь загрузки и повторно откройте меню. Для проверки на компьютере: DevTools → Application → Manifest и Service workers. Манифест и все четыре кэшируемых файла должны загружаться без 404, а worker — активироваться. Установка приложения сама по себе не доказывает, что офлайн-кэш уже готов: проверьте следующий шаг.

На iPhone/iPad в Chrome откройте опубликованный адрес, нажмите **Поделиться → Добавить на главный экран → Добавить**. Возможности установленной PWA зависят от системы; работу офлайн также проверьте вручную.

## 4. Проверьте работу без интернета

1. После первого открытия и установки закройте калькулятор.
2. Выключите на телефоне и мобильный интернет, и Wi-Fi.
3. Откройте калькулятор с его иконки.
4. Измените число в таблице и проверьте пересчёт. Проверьте точный просмотр и именованные сохранения.
5. Закройте приложение и снова откройте его без сети: проект должен восстановиться.

Первый запуск с сайта требует интернета. После успешного кэширования калькулятор может работать без сети и без включённого компьютера. При наличии сети Service Worker обновляет сохранённые ответы. Сохранённая страница используется при отсутствии сети.

Офлайн-файлы и проекты находятся в хранилище браузера. Не очищайте данные этого сайта, если хотите сохранить их. Иконка приложения не является резервной копией.

## 5. Где будут сохранённые проекты

Проекты хранятся в localStorage браузера и не отправляются в репозиторий или на GitHub. Компьютер и телефон имеют разные сохранения. Проекты из прежней страницы `file://` не появятся автоматически на новом HTTPS-адресе.

GitHub Pages размещает файлы приложения, а не синхронизирует данные между устройствами. Не переименовывайте репозиторий без необходимости: изменится адрес, с которого запускается установленная PWA.

## 6. Обновления сайта

Загрузите изменённые файлы в ту же ветку `main`. Публикация обновится автоматически. При изменении файлов приложения увеличивайте `CACHE_VERSION` в `sw.js`: текущая версия — `v3`, следующая — `v4`. При обновлении worker кэширует новый набор файлов и удаляет старые версии только для этой области приложения.

На телефоне откройте приложение с интернетом, чтобы получить обновление. Уже установленное приложение и локальные проекты переустанавливать не нужно.
